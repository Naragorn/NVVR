# Development notes

The public repository contains the implementation and automated flow tests for the NVVR proof of concept. Runtime captures, reverse-engineering dumps, installation backups, and historical working notes remain local and are intentionally excluded from version control.

The implementation targets Fallout: New Vegas 1.4.0.525 with xNVSE and a 32-bit DXVK/OpenVR path. Engine addresses and ABI assumptions are version-specific and must be revalidated before any other executable or runtime is used.
